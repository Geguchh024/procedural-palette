# Changelog

## 0.2.0

- New radial viewport dial (Shift+Alt+M) with thumbnail balls, a page ring,
  a value knob, search-by-typing, and a header you can move and minimise.
- Preview thumbnails for all styles and detail overlays, also shown as a
  picture grid in the sidebar.
- Fixed: updating the add-on disconnected materials that were already in a
  file. Shared node groups are now upgraded safely, automatically on file load,
  and *Repair Palette Materials* fixes files that were already affected.
- Fixed: glassy, mirror-like streaks on box-projected patterns (brick, tiles,
  planks, fabric, roofing).
- Applying a style from the dial now only changes the active object.

## 0.1.0

- First release: 122 styles in 13 families, weathering, detail overlays,
  Real Depth, mapping modes, randomise, library and texture baking.
